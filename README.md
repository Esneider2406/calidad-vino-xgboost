# Predicción de calidad de vino con XGboost

## Descripción

Este proyecto implementa un modelo de Machine Learning utilizando el algoritmo **XGBoost** para predecir la calidad de un vino a partir de sus características fisicoquímicas.

La aplicación permite que un usuario ingrese valores como:

- acidez
- alcohol
- pH
- sulfatos
- densidad

y el sistema predice si el vino es de **buena calidad** o **mala calidad**.

El proyecto cubre el flujo completo de un sistema de ML en producción:

- análisis exploratorio de datos
- preprocesamiento
- entrenamiento
- evaluación
- serialización del modelo
- aplicación web interactiva
- despliegue en la nube
